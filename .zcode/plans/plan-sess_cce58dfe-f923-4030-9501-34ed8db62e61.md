# V4.8.4 实施计划：Playwright 进程回收 + 低置信度优惠审查队列

## 问题 1：Playwright 进程泄漏 — 4 层防护

### 根因回顾
1. `_get_browser()` 无 Lock → 并发 init 竞争可能启动多个 browser 实例
2. `pw` 句柄是局部变量未保存 → `close_browser()` 无法调 `pw.stop()` 释放 driver 进程
3. `run_source_now` fire-and-forget 无并发限制 → 多个 source 同时 fetch 可瞬间打开大量 context
4. fetch 操作无整体超时 → 页面 hang 住时 context 永不释放
5. 启动时无孤儿 chromium 清理 → 上次崩溃残留进程继续吃内存

### 改动清单

#### 1.1 `intelligence/fetcher.py` — 核心 3 修复

**a) `_get_browser()` 加 Lock + 保存 `pw` 句柄**
```python
_browser = None
_pw = None                    # 新增: 保存 playwright driver 句柄
_browser_lock = asyncio.Lock()  # 新增: 防并发 init 竞争

async def _get_browser():
    global _browser, _pw
    if _browser is not None:
        return _browser
    async with _browser_lock:           # 二次检查 (double-checked locking)
        if _browser is not None:
            return _browser
        from playwright.async_api import async_playwright
        _pw = await async_playwright().start()      # 保存到全局!
        launch_args = {"headless": True}
        if settings.proxy_url:
            launch_args["proxy"] = {"server": settings.proxy_url}
        _browser = await _pw.chromium.launch(**launch_args)
        logger.info("Playwright 浏览器已启动")
    return _browser
```

**b) `close_browser()` 完整关闭 (browser + driver)**
```python
async def close_browser():
    global _browser, _pw
    if _browser:
        try:
            await _browser.close()
        except Exception as e:
            logger.warning(f"关 browser 异常: {e}")
        _browser = None
    if _pw:
        try:
            await _pw.stop()          # 关键: 释放 driver 进程
        except Exception as e:
            logger.warning(f"关 playwright driver 异常: {e}")
        _pw = None
    logger.info("Playwright 浏览器已关闭")
```

**c) 并发 context 限制 + 整体超时**

新增模块级 Semaphore（限制同时打开的 page context 数量）：
```python
_FETCH_SEMAPHORE = asyncio.Semaphore(4)  # 最多 4 个并发 fetch
```

在 `_fetch_page_once` 和 `fetch_text` 的最外层包 `async with _FETCH_SEMAPHORE:` + `asyncio.wait_for(timeout=60)`：

`_fetch_page_once` 改为：
```python
async def _fetch_page_once(url, wait_until, timeout, wait_for=None, wait_for_timeout=10000):
    async with _FETCH_SEMAPHORE:
        browser = await _get_browser()
        context = await browser.new_context()
        await _apply_stealth(context)
        await _apply_resource_blocking(context)
        page = await context.new_page()
        try:
            await page.goto(url, wait_until=wait_until, timeout=timeout)
            if wait_for:
                try:
                    await page.wait_for_selector(wait_for, timeout=wait_for_timeout)
                except Exception as e:
                    logger.warning(f"wait_for 超时 ({wait_for!r}): {e}")
            content = await page.content()
            return content
        finally:
            await page.close()
            await context.close()
```

`fetch_text` 内层 try 块也加 `async with _FETCH_SEMAPHORE:` 包裹（同样模式）。

**整体超时**：在 `fetch_page` / `fetch_page_with_error` / `fetch_text` 的每次 attempt 循环内，给 `_fetch_page_once` 调用包一层 `asyncio.wait_for(..., timeout=60)`。超时抛 `asyncio.TimeoutError` → 被现有 except 捕获 → 重试或返回 None。

#### 1.2 `intelligence/scheduler.py` — 追踪 in-flight tasks

`run_source_now` (247 行) 改为追踪 task，而非纯 fire-and-forget：
```python
_inflight_tasks: set[asyncio.Task] = set()

async def run_source_now(provider: str) -> int:
    from intelligence.sources import get_source_by_provider
    sources = get_source_by_provider(provider)
    if not sources:
        logger.warning(f"手动触发失败：未知 provider '{provider}'")
        return 0
    count = 0
    for source in sources:
        task = asyncio.create_task(_run_source_task(source))
        _inflight_tasks.add(task)
        task.add_done_callback(_inflight_tasks.discard)
        count += 1
    logger.info(f"手动触发 {provider}: 启动 {count} 个 task")
    return count
```

新增 `wait_inflight_fetches(timeout=30)` 供 shutdown 调用：
```python
async def wait_inflight_fetches(timeout: float = 30):
    """优雅等待 in-flight fetch task 完成 (shutdown 时调用)"""
    if not _inflight_tasks:
        return
    try:
        await asyncio.wait_for(
            asyncio.gather(*_inflight_tasks, return_exceptions=True),
            timeout=timeout,
        )
    except asyncio.TimeoutError:
        logger.warning(f"等待 in-flight task 超时 ({timeout}s), 强制取消")
        for t in _inflight_tasks:
            t.cancel()
```

## 问题 2：低置信度优惠审查队列 — 闭环架构

### 设计思路

用户明确要求：**低置信度优惠不入 Promotion 表**。

当前痛点：
- `_alert_low_confidence` 只发飞书告警，ParseResult 数据丢失
- 飞书 webhook 是单向推送，无法回复操作
- 没有任何持久化 → 人工看到告警也无法 "入库"

**方案：新建 `promotion_review_queue` 表**，参照 `ModelCapabilitiesLog` 的 `approved=0` 审查队列模式：
- 低置信度 ParseResult → 持久化到 `promotion_review_queue`（不碰 Promotion 表）
- Dashboard 新增 "优惠审查" 卡片，列出待审条目
- 人工**批准** → 从 queue 取出 ParseResult → 调 `_save_promotion` 入 Promotion 表 → queue 标记 `approved=1`
- 人工**拒绝** → queue 标记 `approved=1`（不动 Promotion 表）→ 数据保留留底

这样 Promotion 表只含高置信度 + 人工确认的优惠，保持干净；低置信度数据不丢失，有完整闭环。

### 改动清单

#### 2.1 `db/models.py` — 新增 `PromotionReviewQueue` 模型

```python
class PromotionReviewQueue(Base):
    """低置信度优惠审查队列 (V4.8.4)

    AI 解析置信度 < threshold 的优惠不直接入 promotions 表,
    而是暂存到此表等待人工审批。参照 model_capabilities_log 的 approved 模式。

    - approved=0: 待审 (dashboard 展示)
    - approved=1 + action="approved": 已批准 (已入 promotions 表)
    - approved=1 + action="rejected": 已拒绝 (不入 promotions 表)
    """
    __tablename__ = "promotion_review_queue"

    id = Column(Integer, primary_key=True, autoincrement=True)
    provider = Column(Text, nullable=False, comment="厂商标识")
    title = Column(Text, nullable=True, comment="AI 解析的活动标题")
    summary = Column(Text, nullable=True, comment="AI 解析的摘要")
    url = Column(Text, nullable=True, comment="活动链接")
    confidence = Column(Float, nullable=True, comment="AI 解析置信度 0-1")
    raw_data = Column(Text, nullable=True, comment="完整 ParseResult JSON (批准时用于入库)")
    approved = Column(Integer, default=0, comment="0=待审, 1=已处理")
    action = Column(Text, nullable=True, comment="approved / rejected (approved=1 时有值)")
    created_at = Column(DateTime, default=func.now())
    reviewed_at = Column(DateTime, nullable=True, comment="人工处理时间")
```

#### 2.4 `intelligence/healer.py` — `_alert_low_confidence` 改为持久化 + 告警

```python
async def _alert_low_confidence(result: ParseResult, source):
    """低置信度优惠 → 写入审查队列 + 发飞书告警

    V4.8.4: 不再只发告警丢数据, 持久化到 promotion_review_queue 等待人工审批。
    """
    from intelligence.alerter import send_alert
    from db.engine import async_session_factory
    from db import crud

    # 1. 持久化到审查队列
    raw_data_json = json.dumps(result.model_dump(), ensure_ascii=False)
    async with async_session_factory() as session:
        # 去重: 同 provider + title + 24h 内已有待审条目则跳过
        existing = await session.execute(
            select(PromotionReviewQueue.id).where(
                PromotionReviewQueue.provider == (result.provider or source.provider),
                PromotionReviewQueue.title == (result.title or ""),
                PromotionReviewQueue.approved == 0,
                PromotionReviewQueue.created_at >= datetime.now() - timedelta(hours=24),
            ).limit(1)
        )
        if existing.scalar_one_or_none() is not None:
            logger.debug(f"低置信度审查去重(24h): [{source.provider}] {result.title}")
            return

        await crud.create_promotion_review(
            session,
            provider=result.provider or source.provider,
            title=result.title,
            summary=result.summary,
            url=result.url,
            confidence=result.confidence,
            raw_data=raw_data_json,
        )
        await session.commit()

    # 2. 发飞书告警 (带 dashboard 链接)
    message = (
        f"[低置信度] {source.provider} 发现疑似优惠\n"
        f"标题: {result.title}\n"
        f"置信度: {result.confidence:.2f}\n"
        f"摘要: {result.summary}\n"
        f"链接: {result.url}\n"
        f"已加入审查队列, 请到 Dashboard 确认是否入库。"
    )
    await send_alert(
        message,
        key=f"low_confidence:{source.provider}",
        silence_seconds=3600,
    )
    logger.info(f"低置信度优惠已入审查队列: [{source.provider}] {result.title}")
```

@router.get("/api/promotion-reviews")
async def list_promotion_reviews(
    limit: int = Query(50, ge=1, le=200),

    return {

        "items": [

                "title": r.title,
                "summary": r.summary,
                "url": r.url,
                "confidence": r.confidence,
                "confidence_level": (
                    "high" if (r.confidence or 0) >= 0.8
                    else "medium" if (r.confidence or 0) >= 0.6
                    else "low"
                ),
                "created_at": r.created_at.isoformat() if r.created_at else None,
            }
            for r in rows
        ],
    }


@router.post("/api/promotion-reviews/{review_id}/approve")
async def approve_promotion_review(
    review_id: int,
    session: AsyncSession = Depends(get_session),
):
    """批准低置信度优惠 → 入 promotions 表"""
    review = await crud.get_promotion_review(session, review_id)
    if not review:
        raise HTTPException(404, f"Review {review_id} not found")
    if review.approved == 1:
        raise HTTPException(400, "已处理")

    # 从 raw_data 反序列化 ParseResult, 调 _save_promotion 入库
    from schemas.intel import ParseResult
    from intelligence.healer import _save_promotion
    from intelligence.sources.base import Source  # for type

    raw = json.loads(review.raw_data) if review.raw_data else {}
    # 去掉 _source_type / _intelligence_kind 等内部字段
    raw.pop("_source_type", None)
    raw.pop("_intelligence_kind", None)
    result = ParseResult(**raw)

    # 构造一个轻量 source 对象供 _save_promotion 使用
    from types import SimpleNamespace
    fake_source = SimpleNamespace(
        provider=review.provider,
        source_type=raw.get("source_type", "web_page"),
        url=review.url or "",
    )

    await _save_promotion(result, fake_source)

    review.approved = 1
    review.action = "approved"
    review.reviewed_at = datetime.now()
    await session.commit()

    return {"status": "approved", "review_id": review_id, "provider": review.provider}


@router.post("/api/promotion-reviews/{review_id}/reject")
async def reject_promotion_review(
    review_id: int,
    session: AsyncSession = Depends(get_session),
):
    """拒绝低置信度优惠 → 不入 promotions 表, 保留审查记录"""
    review = await crud.get_promotion_review(session, review_id)
    if not review:
        raise HTTPException(404, f"Review {review_id} not found")
    if review.approved == 1:
        raise HTTPException(400, "已处理")

    review.approved = 1
    review.action = "rejected"
    review.reviewed_at = datetime.now()
    await session.commit()

    return {"status": "rejected", "review_id": review_id}

function renderPromotionReview(container) {
    try {
        const data = JSON.parse(container.textContent);
        const items = data.items || [];
        if (items.length === 0) {
            container.innerHTML = '<p class="loading">✓ 当前无待审低置信度优惠</p>';
            return;
        }
        let html = `<p class="meta">共 <strong>${esc(data.count)} 条待审</strong>，按时间倒序</p>`;
        for (const item of items) {
            const conf = item.confidence || 0;
            const confLabel = item.confidence_level || 'low';
            const created = item.created_at ? new Date(item.created_at).toLocaleString('zh-CN') : '?';
            html += `<div class="pr-card">
                <div class="pr-row">
                    <code class="pr-model">${esc(item.provider)}</code>
                    <span class="pr-display-name">${esc(item.title || '(无标题)')}</span>
                    <span class="pr-conf conf-${confLabel}">${esc(conf.toFixed(2))} · ${esc(confLabel)}</span>
                    <span class="pr-time">${esc(created)}</span>
                </div>
                ${item.summary ? `<div class="pr-summary">${esc(item.summary)}</div>` : ''}
                ${item.url ? `<div class="pr-summary"><a href="${esc(item.url)}" target="_blank">${esc(item.url)}</a></div>` : ''}
                <div class="pr-actions">
                    <button class="btn-approve" onclick="approvePromotionReview(${item.id}, this)">批准入库</button>
                    <button class="btn-reject" onclick="rejectPromotionReview(${item.id}, this)">拒绝</button>
                </div>
            </div>`;
        }
        container.innerHTML = html;
    } catch (e) {
        console.error('renderPromotionReview failed:', e);
        container.innerHTML = '<p class="loading">渲染失败: ' + esc(e.message) + '</p>';
    }
}

async function approvePromotionReview(reviewId, btn) {
    if (!confirm(`确定批准 #${reviewId} 入库? 将写入 Promotion 表`)) return;
    try {
        const resp = await authFetch(`/dashboard/api/promotion-reviews/${reviewId}/approve`, { method: 'POST' });
        const data = await resp.json();
        if (resp.ok) {
            const card = btn.closest('.pr-card');
            if (card) card.remove();
        } else {
            alert('批准失败: ' + (data.detail || resp.statusText));
        }
    } catch (e) {
        alert('网络错误: ' + e.message);
    }
}

async function rejectPromotionReview(reviewId, btn) {
    if (!confirm(`确定拒绝 #${reviewId}? 不入库, 记录保留`)) return;
    try {
        const resp = await authFetch(`/dashboard/api/promotion-reviews/${reviewId}/reject`, { method: 'POST' });
        const data = await resp.json();
        if (resp.ok) {
            const card = btn.closest('.pr-card');
            if (card) card.remove();
        } else {
            alert('拒绝失败: ' + (data.detail || resp.statusText));
        }
    } catch (e) {
        alert('网络错误: ' + e.message);
    }
}
