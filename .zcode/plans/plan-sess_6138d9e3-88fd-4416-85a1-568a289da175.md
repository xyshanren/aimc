**步骤 2：proxy 新增 `_estimate_cost` 辅助函数**

在 `gateway/proxy.py` `_write_usage_log` 之前新增模块级函数：
```python
def _estimate_cost(
    channel: dict,
    model: str,
    input_tokens: int,
    output_tokens: int,
    cached_input_tokens=0,
    cache_read_input_tokens=0,
    cache_creation_input_tokens=0,
) -> Optional[float]:
    """按当期价格估算费用（元）。

    价格单位 = 元/百万tokens，token 数需除以 1_000_000。
    三类 cache token 互斥（同一请求只有一种风格）：
    - cached_input_tokens (OpenAI cache_hit) → cached_input_price
    - cache_read_input_tokens (Anthropic cache_read) → cached_input_price
    - cache_creation_input_tokens (Anthropic cache_write) → cache_write_price
    非 cache 的 input 部分按 input_price 计费。
    """
    from gateway.router import route_engine
    current_hour = datetime.now().hour
    price = route_engine._get_current_price(channel, model, current_hour)
    if price is None:
        price = route_engine._get_fuzzy_price(channel, model, current_hour)
    if price is None:
        return None

    input_price = price.get("input_price") or 0.0
    output_price = price.get("output_price") or 0.0
    cached_price = price.get("cached_input_price")  # 可能为 None
    cache_write = price.get("cache_write_price")     # 可能为 None

    # cache 命中的 input 部分按 cached_price（若有）计费，否则按 input_price
    cache_hit_tokens = (cached_input_tokens or 0) + (cache_read_input_tokens or 0)
    normal_input_tokens = max(input_tokens - cache_hit_tokens, 0)

    cost = 0.0
    cost += normal_input_tokens * input_price
    cost += (output_tokens or 0) * output_price
    if cache_hit_tokens > 0 and cached_price is not None:
        cost += cache_hit_tokens * cached_price
    elif cache_hit_tokens > 0:
        # 无 cached_price 定价，fallback 按 input_price（保守）
        cost += cache_hit_tokens * input_price
    if (cache_creation_input_tokens or 0) > 0 and cache_write is not None:
        cost += (cache_creation_input_tokens or 0) * cache_write

    return cost / 1_000_000  # 元/百万tokens → 元
```

**步骤 2：新增 `_promotion_to_price_rows` 函数（healer.py）**

在 `_save_promotion` commit 之后调用。逻辑：
1. 从 `result.discount_desc` + `result.content` 正则解析折扣率（如 "5折"→0.5、"半价"→0.5、"X折"→X/10）
2. 查该 provider 的 active channel + 该 channel 下所有 model 的当前 normal 价格行
3. 对每个 model，用 折扣率 × 当前 input_price/output_price 算出优惠价
4. 调 `sync_price_change(provider, model, promo_input, promo_output, price_type="promotion", is_promotion=1, effective_from=result.start_date, effective_to=result.end_date)`
5. 调 `apply_price_change_to_route_cache` 刷新路由

```python
import re as _re

# 匹配 "5折" "半价" "8.5折" "打5折" "5折优惠" 等
_DISCOUNT_RE = _re.compile(r"(\d+(?:\.\d+)?)\s*折|半价")


async def _promotion_to_price_rows(result: ParseResult, provider: str):
    """高置信度优惠 → 限时优惠价格行（P0-4 打通核心卖点）。

    从 discount_desc/content 解析折扣率，乘以当前 normal 价生成 promotion 价行。
    price_type="promotion", is_promotion=1, effective_from/to 来自 result 日期。
    路由侧 _is_price_effective 自动按日期生效/失效，零改动消费。
    """
    from intelligence.pricing_sync import sync_price_change, apply_price_change_to_route_cache
    from db.engine import async_session_factory
    from db.models import PriceSnapshot
    from sqlalchemy import select

    # 1. 解析折扣率
    text = f"{result.discount_desc or ''} {result.content or ''}"
    m = _DISCOUNT_RE.search(text)
    if not m:
        logger.debug(f"优惠转价格行跳过(无法解析折扣率): {provider} {result.title}")
        return 0
    if m.group(0) == "半价":
        discount = 0.5
    else:
        raw = float(m.group(1))
        discount = raw / 10.0 if raw >= 1 else raw  # "5折"→0.5, "0.5"→0.5
    if discount <= 0 or discount >= 1:
        logger.debug(f"优惠转价格行跳过(折扣率异常 {discount}): {provider}")
        return 0

    # 2. 查 provider 的 channel + 当前 normal 价格行
    async with async_session_factory() as session:
        from db import crud
        channel = await crud.get_channel_by_provider(session, provider)
        if not channel:
            return 0
        stmt = select(PriceSnapshot).where(
            PriceSnapshot.channel_id == channel.id,
            PriceSnapshot.price_type == "normal",
        )
        rows = (await session.execute(stmt)).scalars().all()

    if not rows:
        logger.debug(f"优惠转价格行跳过(无 normal 价基础): {provider}")
        return 0

    # 3. 逐 model 生成 promotion 价行
    effective_from = result.start_date
    effective_to = result.end_date
    synced = 0
    for row in rows:
        if row.input_price is None and row.output_price is None:
            continue
        promo_input = row.input_price * discount if row.input_price else None
        promo_output = row.output_price * discount if row.output_price else None
        change = await sync_price_change(
            provider, row.model, promo_input, promo_output,
            source="crawler", price_type="promotion",
            is_promotion=1,
            effective_from=effective_from, effective_to=effective_to,
        )
        if change and change.changed:
            await apply_price_change_to_route_cache(change)
            synced += 1

    if synced:
        logger.info(
            f"优惠转价格行: {provider} {result.title} 折扣={discount} "
            f"→ {synced} 个 model 生成 promotion 价行 "
            f"(effective {effective_from}~{effective_to})"
        )
    return synced
```

    def _get_current_price(self, channel: dict, model: str, current_hour: int) -> Optional[dict]:
        """获取渠道在指定模型和当前时段的价格（P0-4: promotion 行优先）"""
        normal_match = None
        for p in channel["prices"]:
            if p["model"] != model:
