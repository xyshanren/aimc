## 6 个 P0 commit (架构地基)

### P0-1 `c54dd48` feat(db): ModelGroupMember 加 FK + UNIQUE 强约束

**背景**: 历史上 `model_group_members.group_id` 字段同时存 int string 和 string,
导致 router `_group_members_cache` 永远 miss → 503.
C1 (0afd0a2) 在 router 层加了防御性归一化, 但 db 层无强约束.

**改动**:
- `db/models.py`: `ModelGroupMember.group_id` 加注释 (FK 强约束)
  + `UniqueConstraint("group_id", "model_id")`
- `db/migrations/2026_08_14_p01_mgm_fk_unique.py`:
  - 清理 3 行孤儿 (`scene:free` group 已删, member 残留)
  - 清理 9 个重复 (同 group+model 多行, 留 priority 最低)
  - recreate 表加 `FOREIGN KEY (group_id) REFERENCES model_groups(group_id)`
    + `UNIQUE INDEX uq_mgm_group_model_active WHERE is_active=1`
  - `PRAGMA foreign_key_check` 验证通过

**执行**:
```bash
python db/migrations/2026_08_14_p01_mgm_fk_unique.py --apply
systemctl --user restart aimc
```

### P0-2 `df01e78` feat(db): price_snapshots + model_registry schema 扩展

**背景**: 硅基流动 `model_id` 是 raw_id (e.g. `zai-org/GLM-5.2`),
router 内部用归一化 mid (e.g. `glm-5.2`), 缺 `raw_model_id` 字段;
缺缓存价格 (`cached_input_price`/`cache_write_price`) 支持 prompt cache.

**改动**:
- `price_snapshots` 加列:
  - `raw_model_id TEXT` (上游原始 ID, proxy 用这个发请求)
  - `cached_input_price REAL` (缓存命中输入价)
  - `cache_write_price REAL` (缓存写入价)
  - `currency TEXT DEFAULT CNY`
  - `is_promotion INTEGER DEFAULT 0`
  - `UNIQUE INDEX uq_ps_channel_model`
- `model_registry` 加列:
  - `raw_ids TEXT` (JSON: 各渠道上游原始 ID 映射)
  - `supports_prompt_cache INTEGER DEFAULT 0`
- migration: 加列 + backfill (price_snapshots.raw_model_id=model, currency=CNY,
  model_registry.raw_ids='{}') + 删 1 行 deepseek_official/deepseek-v4-flash 重复

**执行**:
```bash
python db/migrations/2026_08_14_p02_price_cache_schema.py --apply
systemctl --user restart aimc
```

### P0-4 `388c00e` feat(router): router cache TTL + db file mtime 监听

**背景**: POST_V464_FIXES.md "db 改了必须 systemctl restart" 是运维陷阱;
依赖 APScheduler 300s 定时 refresh (d9c04c0 I6) + 精准 invalidate 接口.

**改动**:
- `gateway/router.py`:
  - `ROUTER_CACHE_TTL_SECONDS` env (默认 60s)
  - `_last_db_mtime` 字段 (db 文件 mtime 缓存)
  - `_auto_refresh_if_stale()` 方法 (TTL + mtime 双重检测)
- `gateway/routes.py`: chat_completions 入口前 `await _auto_refresh_if_stale()`

**效果**: db 改了 (sqlite3 CLI / 修复脚本 --apply / dashboard 操作) **立即生效**,
不需要 restart service.

**执行**: 默认 60s TTL, 可调 `AIMC_ROUTER_CACHE_TTL=10` 更激进.

### P0-5 `7a74176` feat(security): accounts.encryption_version + master_key 启动校验

**背景**: 历史上 master key 改过, 旧 ciphertext 解密失败 (5/6 账号);
router 只 WARNING, 没法快速定位"哪个 key 版本错".

**改动**:
- `accounts` 加列 `encryption_version INTEGER DEFAULT 1`
- migration: backfill 6 行为 v1
- `config.py` Settings 加 `@field_validator("aimc_master_key")`:
  64 字符 hex 校验, 错误直接 `ValueError` 启动失败

**执行**: migration 跑 + service 自动校验 (无需操作)

### P0-6 `d36c384` feat(quota): 多维限额模型 (account_quotas + quota_check)

**背景**: 6 渠道限额语义都不同:
- `minimax TokenPlanMax`: 5h rolling + 周 rolling (2027-06-25 到期)
- `sensenova`: 免费试用 + 并发
- 其他按量: RPM/TPM + 余额
- 单 `channel_quota` 表 (qpm/tpm/daily/total/concurrent) 不够.

**改动**:
- 新表 `account_quotas` (account_id, dimension, limit_value, window_seconds, reset_strategy, enabled, notes)
- 新表 `account_quota_usage` (account_id, dimension, window_start, used_value, last_updated)
- `accounts.quota_plan TEXT` 字段 + backfill (minimax→token_plan_max / sensenova→free_trial / 其他→pay_as_you_go)
- `gateway/quota.py` 新模块:
  - `check_account_quota()` 多维检查, 返回 `(allowed, reason)`
  - `increment_usage()` / `decrement_concurrent()` 累加/释放
  - rolling / fixed_daily / fixed_weekly 窗口管理
- `scripts/seed_account_quotas.py`: 6 channel 配置 (18 行 quota)
- `gateway/routes.py`: 路由后 await quota_check, 超额返回 429 + retry-after

**执行**:
```bash
python db/migrations/2026_08_14_p06_account_quotas.py --apply
python scripts/seed_account_quotas.py --apply
systemctl --user restart aimc
```

## 1 个 P1 commit (鉴权分层)

### P1-7 (即将): feat(security): dashboard 鉴权 (跟 api_key 分开)

**背景**: 当前 `http://192.168.56.12:8080/dashboard/` LAN 内裸开
(brief 里的"已知遗留"). dashboard 数据敏感 (账号/限额/优惠),
应该跟 `/v1/*` API 鉴权分开.

**改动**:
- `config.py`: `dashboard_token` 字段 + `dashboard_auth_enabled` property
  (env var: `AIMC_DASHBOARD_TOKEN`, 跟 `AIMC_API_KEY` 命名一致)
- `gateway/middleware.py`: `_DASHBOARD_AUTH_WHITELIST` + `_extract_dashboard_token()`
  + RequestLoggingMiddleware 加 dashboard 鉴权分支 (支持 3 种 token 传递方式:
  Authorization header / Cookie / ?token= query)
- `dashboard/routes.py`: `/dashboard/login` (HTML login 页) +
  `/dashboard/api/auth/{status,login,logout}` 三个端点
- `dashboard/static/app.js`: `authFetch()` wrapper 自动加 token,
  htmx:configRequest 全局 header, htmx:responseError 处理 401 跳 login
- `.env.example`: 加 `AIMC_DASHBOARD_TOKEN=` 说明 + 生成方式

**向后兼容**: `AIMC_DASHBOARD_TOKEN` 未设 = 维持 legacy 行为 (LAN 内裸开),
跟 brief 里的"已知遗留"一致.

**启用**:
```bash
# 生成 token
echo "AIMC_DASHBOARD_TOKEN=$(openssl rand -hex 32)" >> /home/lxc/aimc/.env
systemctl --user restart aimc

# 浏览器访问 http://192.168.56.12:8080/dashboard/ 会重定向到 login
# 输入 token 即可, cookie 7 天有效
```
