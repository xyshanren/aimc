# aimc

#### 介绍
aimc（AI Model Compass） 是一款专为个人开发者设计的轻量级 LLM 网关与优惠情报聚合工具。

它持续监控 DeepSeek、Qwen、GLM 等主流厂商的定价与活动变动，结合实时时段与频限状态，在完全不侵入业务代码的前提下，将你的 API 请求自动透传路由至当前最具成本效益的渠道。旨在用最低的维护成本，榨干每一分优惠额度。
